# Вторая версия пилота

## Цель

Исправить разделение товарных позиций и выполнять
фильтрацию на уровне отдельных товаров.

## Проблема первой версии

Первоначальный фильтр искал признаки по объединённому
тексту контракта. Признак ПЦР мог находиться в одной
позиции, а целевая нозология — в другой.

Например:
- ПЦР на герпес;
- ИФА на ВИЧ.

Такой контракт мог ошибочно проходить фильтр.

## Подход второй версии

1. Восстановить границы товарных позиций.
2. Проверить качество разделения.
3. Искать ПЦР и целевую нозологию внутри одной позиции.
4. Включать контракт, если найдена хотя бы одна
   целевая позиция.

## Целевая позиция

В названии одной позиции присутствуют:
- явный признак ПЦР;
- хотя бы одна нозология: ВИЧ, гепатит B или гепатит C.

Дополнительные нецелевые нозологии не отменяют
целевую классификацию.

## Планируемые файлы

- config/position_rules.json — конфигурация правил.
- Python-обработчик разделения и классификации.
- new sample analysis 

## Состояние

Создание этой папки не означает, что исправленный
фильтр уже реализован и проверен.
